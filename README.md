# Hunter Flechsig

M.S. Robotics & Autonomous Systems at Arizona State University (B.S. Computer Science).
I build robot software, computer vision and ML experiments, and the C++/Python systems around them.

## Selected work
- **Ramp-climbing and line-following robot** — RP2040, Lingua Franca, IMU and encoders · realtime-embedded-robotics
- **INR super-resolution study** — SIREN / WIRE / FINER at 2× and 4×, PSNR / SSIM / LPIPS · inr-activation-super-resolution
- **Active contours from the paper** — implicit solver, interactive tools · snake-active-contour
- **Tic-tac-toe bot** — C++23 minimax, pybind11, Flask, React, Docker · live demo
- **Distributed parity storage** — UDP protocol, rotating XOR parity, node recovery · demo video
- **WebGL graphics** — Phong shading, hierarchical animation · live demos

## Currently
Medical image analysis coursework: multi-dataset chest X-ray pretraining (Ark+) on ASU's Sol cluster.
